# 研究工具

数据工具中的「研究工具」提供五个分区：模拟持仓体检、产业指标、港股补充、事件日历、本地资料库。保持现有主题与红涨绿跌配色。

## 使用

- 模拟盘右上角「持仓体检」直接进入当前账户。集中度、波动、相关性与风险贡献按币种分开计算；至少20个共同历史收益样本。缺失不补零，不穿透ETF持仓。静态当前权重试算不是账户真实净值，也不含现金。
- 产业指标包括GPU可租挂单统计、社区存储现货存档、台湾PCB/光通信供应链月营收。月营收期间、公布日期和抓取日期分开。社区DRAM存档不是HBM成交价。
- 港股补充包括南向每日流向、个股持股、派息原文和AH对应价差。百万港元在边界换算为港元，比例为小数；派息币种保留方案原文。AH不同市场与汇率报价时间不一致时标为跨时点参考，不能当同时可成交价差。
- A股事件包含股票财报预约及除权除息；美股使用Nasdaq财报预计日期；港股包含派息与披露易历史已发布业绩。预计不等于确认，历史不能推出未来预约。ETF/指数公司财报不适用时明确提示。A股分析页读取事件后可在日K对应日期显示标记；它不会生成历史信号或订单。
- 资料库支持PDF、DOCX、TXT、MD。文件由用户手选导入，最多50份、100MiB、总计50万字/500页；单份10MiB。PDF引用真实页码，Word引用段落；扫描PDF不进行OCR、不虚构文字。导入与检索只在本机，只有用户点AI或要求助手检索资料时才将命中片段发送给配置的模型。

## 缓存与分析

进入页面只读取已保存快照，点「读取/更新资料」才取外部数据。最多3个研究取数任务、64个缓存键；失败保留上次有效结果，部分失败的产业序列单独标记旧日期。页面复用查询缓存，切换证券/账户不显示上一上下文的结果。新功能不进入交易、策略、实时行情热路径。

个股/ETF报告增加带证券、资料日期、单位及价格口径的证据编号和确定性价位距离计算。报告完成后核对当行引用与数值，未对应数字显示复核列表；不因资料中别处存在相同数字就放行。该核对不验证语义因果、预测准确率或盈利能力，不改变应用既有的分析权限。

目前历史分页最多300条；付费数据、逐笔Level2、ETF成分穿透与交易所真实账户写入不属于本功能。新功能不会自动调用AI、调整账户或下单。

## 开发与来源

后端扩展`research.tools`、前端`/research-tools`按既有注册机制加载，接口前缀`/api/custom/research-tools`。新个人文件仅写`data/research_tools/library/`，公开资料快照写`data/research_tools/cache/`。现有账户和账本只读，不迁移。

参考Vibe-Research的数据目录、风险体检与证据思路，记录见`docs/third-party/vibe-research.md`。第三方服务可延迟、停更或限流，端点存在不等于全市场、全历史或实时覆盖。
