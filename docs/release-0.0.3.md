# stockfund-panel 0.0.3

本版本更新首页刷新、行情状态展示、图表范围和 OKX 模拟账户检查。

## 首页与刷新

- Codex 命令可用性探测和共享配置读取增加短时缓存，减少重复探测与读取。
- 行情 SSE 更新会触发首页聚合数据重新查询。
- 轮询间隔从每轮开始时计时，处理结束后不再额外等待一个完整间隔。

## 行情状态与分钟数据

- 状态信息分别展示本机取数时间、来源数据时间和处理耗时；统计口径注明 ST 与北交所范围。
- 股票和 ETF 分钟数据的空响应可恢复；最新视图会自动唤醒；指数跟随最新数据的视图与手动选择历史日期的视图分开。

## 图表研究

- 主分析图新增近 1、3、6 个月、1 年和全部已加载范围，并支持起止日期选择。
- 调整图表范围时保留当前缩放位置。

## OKX 模拟账户检查

- 新增只读运行条件检查，展示账户模式、杠杆和委托设置差异。
- 已知配置错误会单独反馈，不再统一折叠为批量失败。
- 检查不会修改交易所账户模式或杠杆，也不会自动启用相关设置。请在页面中核对现有账户配置后再使用。

## 使用边界

免费数据轮询仍受来源和平台限制，来源数据也可能存在延迟。页面区分来源时间、本机取数时间和处理耗时，不代表数据准确性保证。账户设置需要由使用者自行核对；本版本不会代为更改。
