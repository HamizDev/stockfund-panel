# 市场快讯

进入左侧 **快讯**（`/news`），查看财联社电报与东方财富 7×24 的公开快讯。两个来源不需要填写 API Key；适配器直接访问来源接口，不依赖安装 AKShare。接口可能限流、延迟或变更，页面分别显示各来源状态及拉取时间。

## 视图与筛选

- **全市场**：当前来源快照，按发布时间倒序展示，保留原文入口。
- **个股**：仅显示明确提及本地股票 / ETF 的快讯。
- **Serenity**：上游与关键环节、估值变化、机构行为、产业趋势等本地词表视图。
- **我见山**：风险、政策、重大事件、公司公告、产业题材等本地词表视图。
- 搜索标题、摘要、关联名称或代码；可筛选来源，或只看本地自选 / 登记持仓的关联快讯。

视图名称参照界面示例，**词表由本项目维护，不代表同名作者的方法或背书**。点击“分类规则”查看口径；每条快讯显示命中词。规则按顺序匹配、风险优先；相关度分数为类别权重加每个命中词 3 分，上限 100。分数不是胜率、收益或新闻重要性的概率。

正向词 / 负向词只是词语初筛。否定、引述、上下文与发生时间仍需核对；已对部分明确否定、逆回购协议和国债中标利率做窄范围排除。公司公告和产业题材采用中性分类，不默认标成利好。

关联仅使用已同步的股票 / ETF 维表，匹配明确的完整名称或代码。短名不自动按部分字符或行业联想配股；普通场外基金代码不用于关联同码股票。点击关联标签可打开现有标的预览。未同步维表时页面显示功能降级；未匹配不表示没有相关新闻。关联本身也不能证明受益。

同日标题规范化后相同、摘要相同或互为完整前缀的记录才合并，保留各来源原文与发布时间；同标题但摘要冲突的记录分开。不同日期或不同措辞不会模糊去重，可能保留重复报道。

## AI 解读

点击单条 **解读**，或顶部 **AI 今日研判**，复用“设置 → AI”中的供应商、模型和推理档，包括本机 Codex。仅使用服务器已取得的快讯样本及关联信息；不读取券商账户，不执行交易。

页面加载和刷新不会自动调用模型。点击后会把所选公开快讯和关联标的交给已配置的 AI 服务，并消耗相应额度。报告区显示实际模型、推理档与生成时间。关闭报告面板不会取消后台任务；再次点击同条快讯可接回任务或完整缓存。服务停止会中断尚未完成的任务。

今日研判最多取当前快照中北京时间当天最新的 40 条样本，每条摘要最多 2,000 字符，超出时提示截断。这是来源样本摘要，不能代表全部市场。报告区分事实、影响推断、反向证据、数据缺口与条件式观察计划；缺少行情、估值和市场广度时，不生成无依据的买卖点、仓位或市场周期结论。

同资料、同规则和同模型复用已完成报告；失败不保存为成功报告。同一时刻最多运行一个快讯 AI 任务。AI 文字中的来源名称按文本展示，可点击的原文入口由来源适配器提供，避免把模型生成的任意 URL 当作已核对来源。

## 缓存、空间与故障

- 开着页面时每 120 秒刷新，后端合并并发拉取；手动刷新最短间隔 15 秒。
- 财联社最多 20 条、东方财富最多 200 条；只保存最新快照，不建立无限增长的新闻档案。
- 一个来源失败时保留它的最近有效缓存，并标记旧缓存；不修改原发布时间或假装已取得新消息。另一个来源仍可工作。
- 缓存位于运行数据目录的 `news/snapshot.json` 与 `news/analysis.json`，最多保留 60 份已完成报告，每份上限 40,000 字符。通常占数 MB，取决于正文和报告长度。
- 快讯功能不增加新的账号权限、后台交易任务或个人密钥；数据和配置文件不随开源源码发布。

接口字段参考 [AKShare 的股票新闻文档](https://akshare.akfamily.xyz/data/stock/stock.html) 中 `stock_info_global_cls` / `stock_info_global_em`，并以来源实际响应校验。公开可访问不等于无限制授权；使用时应自行核对来源条款。
