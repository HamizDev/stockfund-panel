# 0.0.10 更新说明

本次增加按需研究工具与报告数字核对，继续沿用既有深色界面、红涨绿跌和 A/HK/US 分区。公开 AI 分析保持客观研究，不新增买卖、加减仓、持有或仓位操作结论。

## 研究工具

「数据工具 → 研究工具」提供五个栏目；模拟盘也可直接进入所选账户的持仓体检。

- **持仓体检**：只读模拟持仓，按币种计算市值权重、集中度、相关性、波动与风险贡献。风险计算至少需要20个共同历史收益样本，不补齐缺失价格；现金不纳入持仓权重，ETF不穿透成分。静态当前权重试算不代表真实净值或策略回测。
- **产业指标**：GPU可租挂单统计、社区存储现货存档、台湾PCB/光通信供应链月营收。保留采样日期、营收期间、公布日期和单位；存储价格不是HBM成交价，挂单统计不是已成交租金。
- **港股补充**：南向每日流向、个股持股、派息方案原文和AH对应价差。证券身份不匹配时排除记录；A/H/汇率时点不一致时明确标为跨时点参考。
- **事件日历**：A股股票财报预约及除权除息、美股Nasdaq预计财报日期、港股派息与披露易已发布业绩。历史公告不推断下一次预约日期；预计不等于确认。A股分析页可显示对应日K事件标记。
- **本地资料库**：用户手选PDF、DOCX、TXT、MD导入与检索，PDF保留实际页码，Word使用段落引用。单份10MiB，累计最多50份、100MiB、50万字符和500页；扫描PDF不做OCR。原文件在使用者本机保存，按需AI解读仅发送命中摘录。

## 数字核对与缓存

个股/ETF报告增加绑定证券、资料日期、单位与价格口径的证据编号，并对价位距离等使用确定性计算。完成报告后逐行核对引用与数值，显示未对应数字及未知引用。该检查不验证语义因果、未来预测或盈利能力，也不把其他位置的同值数字当成有效引用。旧报告继续可读，不改写历史文件。

进入页面只读已保存快照，点击「读取/更新资料」才访问外部源；AI解读也需手动触发。研究取数最多3个并行任务、64个缓存键，失败保留旧快照，部分更新失败的产业序列保留旧日期并单独标记。查询复用既有缓存与取消机制，新功能不进入实时行情或自动模拟执行链路。

## 验证与限制

执行研究工具、分析报告、助手与公开分析边界的相关后端回归，以及前端组件回归、TypeScript和生产构建；检查桌面及窄屏页面，并复核源文件与构建产物中的敏感特征。Windows符号链接权限相关用例在当前环境跳过，其他平台与全部市场时段的持续可用性没有因此得到证明。

免费源可能延迟、限流或缺字段；港股历史分页最多300条，港股未来财报预约仍可能缺失，数据缺失不等于数值为零。本仓库不发布个人data、资料库文件、密钥、登录态、私有分析提示词或个人账户截图。本次新增PDF解析依赖pypdf，未引入第三方CLI或修改交易所账户设置。
