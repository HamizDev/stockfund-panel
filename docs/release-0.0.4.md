# stockfund-panel 0.0.4

发布日期：2026-10-17。

本版本增加本地 Jevos 辅助分析，并改进 OKX 官方模拟的错误诊断。

## 本地 Jevos 辅助分析

- 快讯增加独立的正面线索、风险线索、正负混合和待核对标签，可展开查看判断时间及模型分数。
- 复用现有标的关联，显示自选和登记持仓的相关名称。名称关联不表示该标的一定受益。
- OKX 官方模拟多策略面板增加原信号与本地辅助意见对照，展示对应已收盘 K 线、生成时间和最近记录。旧 K 线意见单独标记为历史。
- 意见仅用于研究对照，不改变策略信号、下单、额度、杠杆、止损或启停状态。模型概率不是交易胜率。

## 队列、缓存和失败隔离

- 新闻和策略只向有界后台队列提交公开文本及行情摘要；模型推理不在原请求或交易循环中等待。
- 每轮最多安排 40 条快讯，优先处理与关注或登记持仓有关的内容。队列最多 64 项、派生结果最多 400 条。
- 缓存根据输入内容、关联上下文、规则版本和模型指纹失效；内容变化时隐藏旧判断。
- 本地服务离线、超时或响应异常时显示独立状态，原快讯和模拟功能继续运行。
- 本地适配禁用环境代理、重定向和外部服务回退，并检查响应大小、模型身份和有限概率范围。

## OKX 官方模拟诊断

- 区分网络错误、HTTP 状态和交易所错误码，界面展示安全的诊断信息。
- 仅在客户端订单编号匹配时采用单笔返回错误码，不回显交易所原始错误消息或凭据。
- 结果不明确时继续保留原请求并要求对账，不自动重发旧订单或补造成交。

## 使用与升级

1. 先按 [Jevos 使用说明](local-jevos.md)另行启动本地模型服务。模型程序和权重不随看板发布。
2. 打开“快讯”查看本地初筛；在“欧易官方模拟 → 多策略面板”底部查看策略对照。
3. 没有安装或启动 Jevos 时，可继续使用原有功能。更新代码不会自动连接账户或启用模拟策略。

仅新增派生缓存 `data/jevos/advisories.json`，无需迁移现有新闻、策略或交易账本。
本版本不打包个人数据、账户凭据、登录态、私有数据源适配或实际账户截图。

## 验证与限制

已覆盖本地模型适配、缓存失效、异常响应、后台退出、新闻及模拟策略相关回归、前端构建和页面检查。
中文财经判断和交易效果尚未经过足够样本验证；不能用少量判断分数推断策略准确率或未来收益。
前端构建仍有既有 ECharts 大包提示。
