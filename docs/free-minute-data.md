# 免费分钟数据与“全量分钟”

核对日期：2026-10-02。

## 两项能力的区别

- **分钟K (`minute`)**：查询给定标的的分钟数据，适合候选、自选、持仓的盘中观察。
- **全量分钟 (`full_minute`)**：在交易时段持续获取全市场 A 股股票的当日 1 分钟 K 线，供全市场分钟策略与板块聚合读取。它不是“某只股票有分钟数据”，也不表示具有多年全市场分钟历史。

目前检查的免费来源没有提供经过验证、请求量有界、覆盖全市场的分钟端点。因此没有把这些逐标的接口声明为 `full_minute`，也不会仅为凑齐能力数量触发数千标的轮询。

## 免费来源的边界

| 来源 | 能提供什么 | 限制 |
| --- | --- | --- |
| AKShare 封装东方财富 | 单标的 1/5/15/30/60 分钟 | 文档注明 1 分钟仅最近 5 个交易日、不复权；历史 1 分钟开盘价可能缺失。公开网页接口不承诺稳定服务。 |
| 腾讯 / 已有 txquote | 按标的取近期分钟数据 | 当前适配器约 5 日，分钟价格点构造 OHLC；不能当成完整原生分钟 OHLC。批量行情快照不等于批量分钟 K。 |
| BaoStock | 单标的 5/15/30/60 分钟历史 | 不是 1 分钟全市场数据；会话登录与付费 API Key 是不同概念。具体历史可用窗口需实际查询。 |
| 旧 pytdx | 逐证券分页面查询 1 分钟等数据 | 历史深度依服务端；原项目已归档并声明个人学习用途，不作为本项目默认生产接入。 |

分钟数据能增加盘中量价、突破确认和短线时点的观察材料。它不会自动提高 AI 判断准确率，也不能代替复权、费用、财务与基金披露时效。分析一批候选通常只需要这一批的有效分钟数据，而不是先下载全市场。

## 已接入 zzshare 单标的分钟

[zzshare](https://github.com/zzquant/zzshare) 的匿名分钟端点已通过内置插件接入统一 `minute` 路由。`backend/app/plugins/zzshare/` 使用 `GET /v3/market/kline/minute/{symbol}`，对范围查询传 `freq=1min` 与 `start_time` / `end_time`；无时间范围时按单日 `trade_time=YYYYMMDD` 查询。多标的由现有路由拆成逐证券请求，不作为全市场批量接口。

该插件只声明 `minute`，`minute_asset_types=("stock",)`；接受标准 `.SH`、`.SZ`、`.BJ` 股票代码，ETF 和指数会拒绝且不发请求。它不声明 `full_minute`，也不提供实时快照或分钟全市场刷新能力。匿名请求在进程内跨客户端共享 2.1 秒最小间隔；失败请求同样占用间隔，HTTP 429 立即报错、不自动重试。每个空响应保持为空，不会合成 K 线。

每个请求批次最多 30 只去重后的标的，全市场同步入口拒绝这个来源，避免形成数小时的单证券循环。该节流锁只跨同一进程的客户端，不跨不同后端进程；匿名接入应运行单个后端实例。

provider 只接受响应中与请求完全相同的证券代码和合法、有限的 OHLC/时间行；成交量按上游股数除以 100 转为内部手，成交额按元透传，时间转换为北京墙钟 naive。API 的复权约定和可用历史深度尚未验证，因此插件不声明 `minute_history_days`，也不宣称返回原始价或前复权价。单标的历史查询可能逐只耗时，当前没有全市场分钟导入承诺。

统一分钟路由对这个来源执行逐证券、逐交易日的原始收盘锚点检查：必须含 15:00 收盘柱，且与本地原始日K收盘相同，才接受本次完整日的价格。缺请求标的、未收盘、无日K锚点或不一致时，回退已安装的 stock-sdk；没有可用替代源时按原生分钟权限回退，不把未知价基写入分钟库或再次复权。这只是本次返回数据的检查，不是对上游所有历史价格口径的保证。旧前复权分钟库接收已核对的原始柱前，会依据本地有效因子投影为旧口径；因子缺失时沿用现有恒等处理，不能声称完成了复权。已有原始库保持原始柱。ETF 继续用已安装的 stock-sdk。

上游仓库描述了可免费取得 Token，但该 Token 的 HTTP 传递字段尚未核实；当前插件只用匿名请求，未注册 Token 设置或秘密读取能力。

2026-10-01 的匿名单标的实测为 `000001.SZ`、2026-09-30、1 分钟，HTTP 200，返回 240 行，时间范围 09:31–15:00。这个样本证明一次单标的响应，不证明其他证券覆盖、历史深度、长期稳定性、复权语义或全市场能力。ETF `510300.SH` 曾返回 HTTP 500，所以 ETF 明确不走 zzshare。

2026-10-02 完整适配器再取 `000001.SZ`、`600519.SH`、`600036.SH`、`300750.SZ` 的 2026-09-30 数据：每只 240 根、共 960 根，开盘字段完整；各股 15:00 收盘与本地原始日K相同，分钟成交量（手）累计与日K量的整数取整相符。

[stock-data](https://github.com/luke0708/stock-data) 是通达信/网页接口的采集与缓存工具，分钟数据按需积累，README 的整包全量初始化指的是日线；不能按名称把它认作全市场分钟数据集。

[猫爪分钟接口](https://www.numcat.net/api-docs/stock/minute) 文档提供全市场指定分钟快照（最多 6000 行），但需 API Key；[公开价格页](https://www.numcat.net/pricing) 列出的体验与会员版本收费。本次没有获得免费分钟权限的证据，不把它列为已验证的免费方案。

## 接入前的验证

新来源先使用少量标的检验时间、周期、单位、OHLC、历史范围和延迟；区分原生分钟 K 与从价格点构造的走势。全市场接入还需实际证明返回覆盖范围、真实上游请求数、限流和失败语义。单标的样本通过不能证明全市场可用。

开启全量落盘服务会写入本地数据并持续访问上游，应先确认资源预算和来源权限。不要把逐证券抓取循环直接套进默认数秒的全市场刷新调度。
