# 港美股看板缓存

港美看板复用同一个 TanStack Query。离开页面后，观察池、当前图表和产业查询的内存缓存保留30分钟；切换证券会释放该视图中未再使用的旧证券图表。

美元日频利率仍沿用已有的1小时内存缓存，本次不缩短它的缓存周期。

刷新页面或新开标签页时，会恢复此前已取得的公开看板快照，再后台更新。只序列化港/美观察池摘要、每市场最近一份K线、产业模式及美元日频利率；最多8份查询、总计不超过1 MiB，24小时以前的快照不恢复。凭据、账户、模拟盘、个人自选、快讯、Finnhub补充研究及Adanos结果均不写入这份快照。

恢复使用TanStack既有dehydrate/hydrate；集中注册的 `dashboard-public-queries-v1` 属于浏览器本地存储，清除浏览器数据后会丢失。它不增加服务端行情落盘，不改变A股全市场分钟采集或港美按需读取。

后台返回同一市场的空加载响应时，保留上一份已完成报价、市场广度和图表，日期与报价时间保持原值；失败会显示错误和旧缓存提示。不同市场、证券及周期相互隔离。原有深色风格和红涨绿跌保持一致。

第一次访问、缓存被清除或过期时，仍需等待免费源取数。港美广度有分页和分类步骤，缓存能减少重复等待，不能保证上游实时、完整或永远可用。
