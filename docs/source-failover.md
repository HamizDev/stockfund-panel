# 主备数据读取

本机可通过偏好 `data_source_failover_enabled=true` 启用已安装源之间的有限备用。
缺省关闭，原手动数据源配置与其他用户的行为保持兼容。

| 数据 | 本机主源 | 备用与边界 |
| --- | --- | --- |
| A股全市场报价 | stock-sdk | 扶摇；少于1,000条有效股票记录的全市场响应不能冒充完整快照 |
| 核心指数、策略与自选ETF报价 | stock-sdk | 扶摇，只补主源缺失的请求标的；不覆盖主源已经取得的记录 |
| 股票、ETF、指数原始日线 | stock-sdk | TickFlow免费历史日线；各资产继续写各自仓库，缺失标的单独补拉 |
| 股票、ETF 1分钟 | 腾讯 | stock-sdk已核验的原始1分钟数据；异常、空数据、标的或窗口无效时切换 |
| 港美股逐只图表与报价 | Yahoo query1 | Yahoo query2同数据源的备用请求域名；不是独立的第二套行情 |
| 港美市场快照 | 东方财富 | 港股新浪覆盖池与腾讯ETF；美股Yahoo筛选池。覆盖池有独立scope，不冒充全市场 |
| 基金净值和排名 | 既有主备链 | 保留字段、币种、净值日和缺失值约束，不把不同基金或调整净值混用 |
| 快讯 | 财联社与东财各自采集 | 单源失败保留该源旧内容和时间，两种内容不互相冒充 |

## 失败、恢复和缓存

每个来源/数据类型使用独立的有界内存健康记录。失败后冷却30秒，重复失败逐步
延长到最多5分钟；到期允许一次恢复探测，成功后按主源顺序读取。不同请求的旧成功
不能清除更新的故障。失败只保留异常类型，不保存带凭据的URL或响应。

切源不清理原数据或页面缓存。两边都失败时沿用调用方已有的旧缓存或不可用状态，
旧行情不升级成当前行情；图表/AI已有的交易日、当前分钟和完整性检查继续生效。
`GET /api/settings/source-routing` 可查看当前开关、路由、实际成功来源和冷却状态。

扶摇快照的服务器/获取时间不是逐笔报价时间。自动备用返回的此类记录不冒充
真实成交时间，不用于通过ETF短线执行的新鲜度检查或盘后日线定版确认。
腾讯ETF分钟没有成交额时继续返回空值，不用价格乘成交量补造VWAP。

## 仍然独立的数据

- 全市场分钟保留ELTDX。逐只分钟源不是全市场分钟能力的等价替代，失败不能伪装为覆盖完整。
- 五档仍独立选择腾讯，不跨源拼接盘口。
- 因子、分红、财务报表保留原有独立路由，未验证同等口径前不混源改写历史。
- ELTDX的严格失败约束保留；5分钟及以上的分钟价格基础不同，不做未经验证的跨源转换。
- 官方模拟和真实交易所的账户、委托、资金、持仓和行情不跨交易所自动替代。

本机试拉成功与长期稳定性不同；没有免费接口能据此保证永久可用。
