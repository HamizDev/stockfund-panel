# 0.0.9 更新说明

本次集中改进行情容错、页面复用和研究数据时效。A/HK/US 继续分开查看，保持既有深色界面与红涨绿跌。

## 行情与数据

- 按实时、日线、分钟、市场快照能力分别选择备用源，增加有限故障退避与响应内容校验；失败或过期结果不会冒充有效数据。
- A 股实时与未复权日线支持已有免费源之间切换；选中股票/ETF 的 1 分钟查询支持备用。全市场分钟采集与其他周期仍遵循原能力配置。
- 未提供可信源报价时间的备用行情可用于明确标记的展示，不进入当日行情聚合、异动监控或自动模拟撮合。
- Yahoo 公共查询支持同一供应商的备用主机，港美股市场快照按有限覆盖范围回退。目录、行业分类和快照覆盖分别表示，不宣称覆盖全部市场。
- 增加港美股公司财务、香港公司行业归类及可选研究数据配置。需要 Key 的服务仍需使用者自行配置；本仓库不包含凭据，也不保证第三方免费额度长期不变。

具体源、能力与限制见[行情容错](source-failover.md)、[免费行情](free-market-data.md)、[分钟数据](free-minute-data.md)和[可选研究数据](keyed-market-research.md)。公共代码的容错开关默认关闭，部署者按自身数据源配置启用。

## 加载与图表

- 看板切换市场及返回页面时复用已有数据，后台按时效刷新；缓存有容量、有效期和失效边界。
- 选中标的查询、当日分钟结果、基金页面与研究资料减少重复请求，切换标的后避免旧响应覆盖新标的。
- 补充 ETF 分时昨收校验和备用分钟读取，避免缺失基准时显示错误涨跌幅。
- 优化日K日期范围、关键价位数值精度、图表联动与响应式布局；继续显示实际数据日期。

## AI 研究

- 请求分析时补取选中标的当前时段数据，明确提问时间、实际行情截至、完整日K及未完成盘中聚合。上游没有更新时明确披露，不把提问时间当成行情时间。
- 公开版的个股/ETF、基金、选股研究、持仓复盘与全局助手只输出客观状态、支持与反向证据、风险及核对条件，不提供买卖、加减仓、持有等操作结论。
- 持仓复盘保留 `actions[].action` 兼容字段，内容改为研究评估标签。旧版报告文件不删除，但不作为新版中性研究显示；需要时手动重新生成。
- Jevos 快讯处理改进排队和结果复用。模型输出仍需核对，不能把方向标签当作收益、胜率或交易保证。

模拟交易、策略规则和历史成交保持各自职责。本次公开研究边界不取消回测或模拟引擎中已有的买卖规则。

## 验证与限制

发布候选执行后端相关回归、前端回归、TypeScript 检查和生产构建，并扫描公开文件与构建产物中的敏感特征。第三方接口覆盖与可用性可能变化，测试结果不等于所有市场时段的持续可用性。免费源不等同交易所授权的实时 Level 2。

仓库不发布个人运行 data、密钥、登录态、私有数据接入、个人账户截图或本机专用分析提示词。
