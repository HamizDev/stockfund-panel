# 本机图表与官方模拟账户

## 图表

股票/ETF 默认日 K 和数字资产 K 线使用本机 Canvas 渲染。视口、分窗绘图和技术指标的适配参考了用户提供的 DSH `quant-terminal` 源码；不调用 DSH 的 Binance 数据适配器。现有 ECharts 专业图和分时图继续使用原数据链路。

- 日 K 保留现有复权与历史查询，红涨绿跌；提供成交量、均线、布林轨道、锚定 VWAP、买卖标记及研究价格线。ATR14 在数据可用时显示于摘要。
- 从 DSH 适配 Donchian20 研究通道，股票/ETF 和数字资产图表可勾选 `DC20上`、`DC20下`；前 19 根预热期不绘制，不作为当前模拟账户的新交易规则。
- 数字资产保留当前公开行情接口、已收盘 K 线校验、EMA20/60、成交标记和风险线。
- 滚轮缩放、拖动浏览历史、适配视图；十字线显示时间、OHLCV。日 K 的日期点击和价格双击沿用原页面操作。
- 缺失成交量/指标不补零；不把 DSH 的占位财报/股息/拆股、合成债券收益率或未来确认信号用于策略。

图表的研究指标不等于买卖建议，也不更改现有回测撮合和自动模拟规则。

## 官方模拟入口

在「数字资产模拟」页顶部打开「欧易官方模拟」或「Bitget 官方模拟」，也可打开 `/crypto-demo?exchange=okx` 或 `/crypto-demo?exchange=bitget`。

账户查询与「官方模拟执行」分开。原有本地 Bitget 模拟策略继续使用自己的账本；不会自动连到官方账户。模拟执行默认关闭，服务重启后也会关闭；连接成功不会自动启用交易。没有真实交易、撤单、划转或提现接口。

下面的使用步骤对应**基础执行区**（手动订单与单策略自动规则，逐仓 1 倍）。0.0.2 新增的 **OKX 三套独立预设**使用各 10 USDT 保证金预算、逐仓 10 倍和最大入场名义金额 90 USDT，须在其独立面板按预检要求配置；详见[版本说明](release-0.0.2.md#官方模拟与本地模拟)。两类执行功能分别启用，不会自动修改官方账户模式、杠杆或已有持仓。

### 使用步骤

1. 在交易所网站/App 内进入**模拟交易**，领取或重置官方虚拟资金。
2. 在模拟环境创建专用 API Key，记下 Key、Secret 和 Passphrase。仅查询时授予读取权限；使用模拟执行时另需模拟交易权限。正式账户 Key 不能代替模拟 Key。
3. 返回看板，选择交易所；OKX 选择注册站点 Global、US 或 EEA，Bitget 选择账户实际使用的 Classic 或 UTA。
4. 在本地页面填写三个密钥字段，点击「连接官方模拟账户」。请勿把密钥发到聊天中。仅当需要重启后继续连接时勾选「在本机加密保存密钥」。
5. 连接成功后，在余额、持仓、当前委托和最近成交标签查看。查询表格仍为只读；下方独立执行区负责预检、预览、确认与查单。
6. 如需使用基础执行区，先在官方模拟页面把目标 USDT 永续设为单向、逐仓 1 倍。OKX 需合约账户（acctLv=2）；Bitget Classic/UTA 均需明确返回该合约配置。本站不修改这些设置，无法核实时拒绝发单。此处的 1 倍要求不用于上述 OKX 三套独立预设。
7. 在执行区确认模拟专用密钥，设置新增开仓金额上限（默认 10 USDT，最高 100 USDT）和日亏阈值，单独启用。手动订单先预览，再逐笔确认；计划 45 秒过期，价格变化过大须重新预览。
8. 自动规则可绑定同标的的本地 Bitget 策略账户，仅复制规则和止盈止损参数；启用时官方账户必须空仓。不会修改或启用该本地账户。反向先减仓，下一根收盘信号再评估开仓；意外持仓、参数变化或对账异常会暂停。

首版仅支持 BTC/ETH/SOL USDT 永续、一个标的和一个方向持仓，不加仓。OKX 数量按合约张数乘 ctVal 计算，Bitget 下单按基础币和官方步长计算。UTA 持仓接口未明确标注 `total` 单位，因此只允许把本次本站记录的开仓数量与官方原始持仓逐项匹配后减仓；其他已有 UTA 仓位须在官方处理，不猜测换算。日亏与当日 15% 权益回撤阈值只阻止新增开仓，不保证已有仓位的损失上限；暂停不自动平仓、撤单或取消已经在途的请求。市价单金额为下单前估算，最终以官方回执为准。

下单前先持久化唯一客户端订单号。超时或结果不明会暂停，只允许按该订单号查单，不自动重发；未完整成交时保留阻塞，需核对官方持仓。订单日志最多 500 笔、2 MB，达到上限拒绝新增且保留原记录。执行日志在 `data/crypto_demo_trading/`，不包含密钥。

公开 BTC/ETH/SOL USDT 永续行情提供 1 分钟、5 分钟、15 分钟、1 小时和 4 小时周期，不需要账户密钥。公开图表与官方模拟撮合价格可能不同。

### 数据口径

- OKX 账户总权益为 USD，币种余额按原币；SWAP 数量显示合约「张」，不擅自换算成 ETH/BTC 数量。最近成交接口覆盖近 3 天，页面每次最多读取 20 条。
- Bitget Classic 读取 USDT 本位合约账户，合约数量按基础币；Classic 手续费读取 `feeDetail[].totalFee`。UTA 账户总权益为 USD，持仓 `total` 数量未在该 REST 字段表明确单位，页面保留「交易所原始数量」；UTA 委托和成交数量按基础币，手续费读取 `feeDetail[].fee`。
- 当前委托最多 100 条、最近成交最多 20 条；不是账户全部历史。未返回的数字显示 `—`。不同费用币种不相加。
- 任何接口失败都不以空数组或零余额伪装成功。刷新失败时可保留前次成功快照，并显示旧数据提示及快照时间。

### 本机保存和连接保护

默认仅服务器进程内会话，关闭看板服务即需重新连接。勾选保存时，凭据以 Windows 当前用户 DPAPI 加密到 `data/user_data/crypto_demo_credentials.json`；与现有 `.env`、Codex 登录和其他密钥配置分离。不支持 DPAPI 的系统只提供会话连接。

成功的会话连接会替换同交易所以前保存的配置；失败不会覆盖旧配置。「断开本机连接」只清除本站配置，不撤销交易所 API Key、不修改官方持仓或委托。要完全撤销访问，请在交易所删除该模拟 Key。

凭据不存入浏览器存储；提交、取消和切换交易所会清空输入。私有查询保持固定 GET 白名单；执行使用独立的固定路径白名单，只允许模拟下单 POST 及必要的只读预检/查单。两者均强制 OKX `x-simulated-trading: 1` 或 Bitget `paptrading: 1`，不跟随重定向，没有正式交易回退。接口沿用看板登录保护，另限制同源浏览器访问，响应不缓存。
