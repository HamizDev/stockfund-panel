# v1.2.0 · 预测研究与证据复盘

发布日期：2026-11-01。

- 新增可选的 Kronos 通用工作台：Base 日 K / 分钟预测、同快照配置对比、真实行情成绩汇总和候选配置管理。
- 新增研究留档、1／3／5 个交易日事后方向核对及看涨/看跌基线；原结论与后续结果分开保存。
- AI 研究可选一轮反方复核；默认一次调用，开启最多两次。公开分析继续保持中性，不加入操作建议。
- 财务资料按实际披露时间筛选；原价不可核验、报价不全或预测完成晚于首个目标收盘时不生成事前成绩。
- 账户上下文区分手动登记、独立模拟盘和未接入实盘；不推断未知余额、可卖数量或执行权限。
- 改进 StockSDK 日线分批同步、同任务复用和故障回退时间校验，保留已有实时指数和 ETF 处理逻辑。
- 为研究记录增加读取/目录扫描上限及独占临时文件写入，保留取消、重启和原件完整性约束。

使用说明：[Kronos 可选环境与工作台](kronos-research.md) · [研究留档与核对](research-validation.md)。

本版本源码不带权重、个人数据、密钥、私有接入、固定个人标的池或已启用的账户/训练计划。Kronos 需要用户另行安装独立 CUDA 环境；未配置时不影响其他页面。方向一致率不等同于实际交易胜率，未宣称模型已自动学习或产生稳定收益。
