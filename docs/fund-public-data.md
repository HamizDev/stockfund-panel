# 免费基金研究数据

基金中心与 AI 选基可使用东方财富 / 天天基金公开档案，无需提供本项目作者的账号或密钥。网页接口可能调整、延迟或限流，不保证持续可用。

## 已接入与口径

| 字段 | 来源 | 口径与限制 |
| --- | --- | --- |
| 管理费、托管费、销售服务费 | 天天基金购买信息页 | 年费率；`---` 为未知，不自动当作 0 |
| 申购、赎回费 | 同页交易规则 | 保留金额/持有期限条件；固定金额不转换为百分比；平台折扣与公告费率分开 |
| 区间观测最大回撤 | 东方财富累计收益曲线 | 用 `1 + 累计收益率 / 100` 构造收益指数；仅计算选定窗口内的观测回撤，图表采样可能低估每日回撤 |
| 披露股票持仓与权重 | 天天基金投资组合页 | 选最新报告期；不等于当前持仓，也不包括全部现金、债券等资产 |
| 持仓报告期 | 持仓表截止日期或季度标题 | 不用抓取时间替代 |
| 相关报告发布日期 | 天天基金定期报告公告 | 季报与中报可能属于同一报告期，分开展示，不推断哪个公告对应持仓表 |
| 单只基金榜单净值日期 | 东方财富基金排名 | 按基金分别展示；不冒称整张榜单统一统计截止日期 |
| 单位净值 | 原扶摇 / AKShare 链路，失败时直接读取东方财富 | 免费回退不提供复权净值，`adj_nav` 保持空值 |

**仍无法保证补齐：** 未公开的实时完整持仓、统一榜单统计截止日期、费率生效日期、持仓表对应的确切公告日期、完整每日复权基金净值。累计净值不等于分红再投资的复权净值。相关字段缺失时保持空值，并显示来源或缺口。

## 页面与 AI

- 基金详情新增“基金基础研究”，包含费率条件、回撤区间、持仓报告期、公告和来源链接。
- AI 选基先生成最多 16 只历史收益候选，再逐只补公开资料并显示进度，最后调用用户配置的模型。
- 页面保留此次候选的研究快照，与对应 AI 报告一起保存；切换页面后可以继续查看。重新生成候选会重新分析。
- 模型输入持仓限制为权重前 10 只，同时提供全表条数、全表覆盖权重及所列权重，避免把部分持仓当作完整组合。
- 盘中估算只对可取得行情的权重前 10 只发起分时请求；这是披露持仓穿透估算，不是基金公司公布的真实净值。

## 接口与负载

`GET /api/custom/fund/research/011370.OF?horizon=1y` 返回 `fees`、`risk`、`holdings`、`missing_fields`、`warnings`。区间支持 `1m/3m/6m/1y/2y/3y`。

公开请求采用 8 秒超时、全局最多 4 个并发，不自动重试。正常研究资料缓存 6 小时；来源失败或全不可用时缓存 60 秒。后端最多保留 96 个基金/区间结果，前端最多缓存 64 只基金；同一基金/区间的并发请求合并。

这些缓存只在内存中，不写入用户持仓、自选、密钥或原始行情库。现有持仓与净值接口的其他缓存策略保持原样。完整股票研究、策略运行及模拟仓所需的日线、除权因子和交易规则是独立链路。

## 其他数据接入边界

| 数据 | 当前路径 | 需要补充或确认 |
| --- | --- | --- |
| 股票日线、实时、分钟、除权因子 | stock-sdk / 扶摇 / TickFlow 插件 | 检查用户配置的能力；历史因子回填还要核对累计因子与事件因子、覆盖日期及原始价使用规则 |
| 腾讯分时及五档 | 内置 txquote | 免费浅历史不等于完整分钟历史 |
| 财务 / 全量分钟 | 具有对应权限的数据源 | 不能把无权限、未实现 adapter 或缺数据当作已接通 |
| 问财 | 需具体授权接口或合法本地桥接 | 网页可访问不代表已获得开放 API 权限 |
| 通达信 | 需可运行的行情终端或官方 SDK 服务 | 行情接入不等于获得交易权限 |
| 真实自动交易 | 尚未连接账户 | 需用户选券商/API并另行授权；免费行情不自动产生下单权限 |

上述表格描述代码路径，不能代替某位用户运行时的连通检查。不要将个人 `.env`、`data`、扶摇 Key、Codex 登录文件或券商凭证提交到公开仓库。
