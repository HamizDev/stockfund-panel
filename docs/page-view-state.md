# 页面查看状态

研究资料支持股票名称和代码搜索。选择匹配项后读取本机资料缓存；“拉取研究资料”仍需手动点击，不会自动调用 AI。

以下轻量状态在当前浏览器标签页中保留，切换菜单或刷新页面后恢复：

- 研究资料：搜索内容、最近查看的沪深股票及名称。
- 指数：指数、日线区间、仍在返回数据范围内的分时日期；显式链接中的指数优先。
- 数字资产：图表交易对、周期、账户关联和展开项；恢复时重新向服务端验证账户。
- AI 选股/ETF 与 AI 选基：候选搜索、筛选、选择和展开数量；已完成的 AI 报告沿用原缓存。
- 异动/竞价：页签、证券、日期和开盘/收盘阶段。自动读取已有缓存，不自动请求源站拉取。

页面通过集中存储键保存查看选择；缓存值经过校验，损坏或版本不兼容时回退默认值。行情和账本仍从服务端读取，遵循原刷新与有效期规则。保存查看状态不会保存未提交订单、新建账户表单或启停操作，也不会自动重跑 AI。

当前数字资产模拟只连接 Bitget 公开行情；尚未接入欧易 OKX 模拟交易接口。
