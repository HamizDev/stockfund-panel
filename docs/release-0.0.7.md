# stockfund-panel 0.0.7

发布日期：2026-10-19。

本版本集中优化图表指针交互、减少盘后分钟回退的重复请求，并补充港美股中文名称检索和欧易官方模拟重启边界。Jevos 补充标题与正文冲突时的同事件复核，以及新闻规则升级后的缓存失效。

## 图表交互

- Canvas K 线图将静态图表与十字线、价格标签等 hover 反馈放在独立画布层。指针移动只清理和重绘交互层；数据、主题、指标或可视区域变化时仍重绘静态图。此改动减少 hover 引起的重复绘制，不代表全站渲染或接口延迟都下降。
- 保持原有价格与日期标签、指标、响应式尺寸及缩放行为。定向测试检查连续指针移动时静态画布绘制调用不增加，交互层仍更新。

## 分钟回退与港美股搜索

- A 股股票和 ETF 的单标的分钟回退，对历史日期及香港时间当日 15:30 后可缓存的有效结果使用有界进程内短缓存，并合并相同请求的并发上游读取。缓存按数据目录、当前来源、资产类型、代码、日期、频率、复权上下文和本地分钟分区区分；有效期短，来源或本地分区变化会导致重新取数。
- 收盘前的当日回退、空结果、无效结果和失败响应不进入缓存；缓存不写磁盘，不扩大当日分钟查询窗口，也不改变本地分区优先级。缓存只减少短时间内相同回退的重复上游请求，不能消除来源延迟、缺数或限流。
- 港美股中文名称查询在现有本地 / Yahoo 搜索无匹配时，增加腾讯公开名称搜索备用；美股证券目录备用搜索仍用于名称定位。远端候选需由后续行情源核验，不能据此宣称覆盖所有港美股证券、行情实时或报价可用。

## 欧易官方模拟与 Jevos

- 欧易官方模拟仍默认只在本次服务会话运行。用户可在明确启用时单独勾选允许重启恢复；该设置要求相同官方模拟连接已加密保存到本机。服务重启后先核对连接指纹、账户模式、逐仓杠杆、预算、持仓归属和活动委托，通过只读预检后才恢复原规则。
- 未决委托、连接变化、预检失败或暂停会阻止恢复；暂停及连接变更会撤销恢复授权。此前未单独授权的账户不会自动获得该权限。恢复不会修改交易所账户设置，也不接入实盘。
- Jevos 保持原有标题和正文初筛输入，仅在两者方向冲突时增加一次有界合并复核，核对同一主体、同一事件或报告期的正负事实。合并结果明确为混合时才采用，低置信结果保留暂定标记；证据仅使用原文，旧新闻规则产生的当前标签在重启时失效，原审计记录和策略意见保留。它仍是本地辅助分类，不是胜率、收益预测或交易信号。

## 验证口径

- 已通过受影响组件与服务的定向回归，覆盖 Canvas hover 分层、分钟缓存并发与隔离、港美股名称搜索及目录边界、欧易模拟重启恢复条件。Jevos 覆盖冲突合并、原文证据和规则版本失效；小样本对照不足以证明总体分类精度提升，否认业务等个别样本仍可能误判。
- 已通过 326 项相关后端回归、47 项相关前端回归，以及公开版和保留本地私有接入的两套生产构建；预览检查了桌面双图、手机布局和 Canvas 交互。部署后的本机读回另行记录。A 股当日市场已收盘；没有进行开盘期间连续实测，也没有据此推断连续行情、缓存命中率或全站性能提升。
- 本版本未进行实盘交易，不报告模拟或实盘收益、胜率，也不声称自动恢复已获默认授权。

## 兼容与限制

版本号更新不迁移本地行情、模拟账本、个人偏好或密钥。分钟缓存是进程内临时数据，进程重启后清空；缓存命中依赖来源、日期、复权与本地分区上下文一致。

港美股免费搜索和行情依赖公开上游，可能延迟、变化或不可用；搜索候选不等于完整证券目录或行情覆盖。官方模拟账户与本地账本仍需用户核对，轮询与恢复预检不能保证断网期间及时管理订单。Jevos 输出应结合原文人工复核，不应解释为准确率承诺。
