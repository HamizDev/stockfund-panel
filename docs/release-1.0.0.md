# 1.0.0 · 加载与聚合性能

发布日期：2026-10-27。

本版从0.0.11升级至1.0.0，作为后续版本号的新起点。沿用现有界面、红涨绿跌及分组导航；应用版本升级不改变扩展API版本，也不迁移账户或行情数据。

## 加载与刷新

- 前端扩展模块并行导入，再按原有排序注册。重复ID、路由冲突的处理顺序和单模块错误隔离保持一致。
- 总览同一仓库、报价服务、盘口服务及日期上下文的并发冷请求共享一次计算；不同日期与上下文分别处理。
- 总览缓存使用单调时钟，从构建完成时开始计算5秒有效期。刷新操作使旧代构建失去写回资格，避免旧结果覆盖新快照；失败结果不缓存。
- 概念与行业在同次总览构建中共享扩展数据读取，按实际字段取数，保留快照、时间序列、缺失字段和读取失败的兼容处理。
- SSE已连接时，侧栏告警总数每60秒核对一次；断连或重连时仍为15秒。后台标签页不做周期轮询，SSE告警事件继续即时失效刷新。

## 可复核的性能范围

以下是受控环境中的工作量或模块基准，不能换算成所有页面的实际提速比例：

| 场景 | 修改前 | 修改后 |
| --- | --- | --- |
| 9个扩展模块各模拟12ms导入延迟，7轮中位耗时 | 145.117ms，串行 | 20.920ms，并行导入 |
| 同一上下文8个并发总览冷请求 | 构建8次 | 构建1次，响应一致 |
| SSE稳定连接时侧栏告警总数周期请求 | 4次/分钟 | 1次/分钟，事件触发请求另计 |
| 30个分区各1000行的板块聚合，5轮中位耗时 | 111.699ms | 61.820ms，输出一致 |

板块读取的回归使用隔离合成Parquet数据，对比概念与行业的最终结果，并检查读取工作量；5轮行数据文件读取从300次降至5次，同时增加150次逐文件schema元数据检查。只有规范分区且所有分区schema一致时才裁剪到最新日期；混合布局或schema不一致时回退兼容读取。测试不使用个人行情、账户或持仓样本。外部数据源的网络延迟、免费源覆盖和上游限流仍会影响实际等待时间。

## 公开研究边界

基金候选使用“证据支持、证据分歧、风险需复核、资料不足待核实”标签，描述事实、风险和待核实条件。公开AI研究模板不提供买卖、加减仓、持有、申购赎回或个人仓位操作结论；结构化持仓评估继续拒绝操作标签，不复用旧版本操作报告。

策略筛选、历史回测和模拟账户继续按已有规则运行，规则触发和模拟成交不等同AI研究建议。模型文本仍需核对事实和数据日期；提示词和结构化验证不代表对任意模型自由文本的绝对语义保证。

## 升级与回退

按原部署方式更新源码并重新构建前端即可。依赖版本、数据源配置、费用及账户设置保持原值；无需重新导入个人数据。回退时恢复上一版本源码与前端构建，保留原运行数据。

前端发布仍保留旧哈希资源，避免已打开标签页切换页面时出现资源404。本版本不包含个人数据、访问凭据或私人研究配置。
