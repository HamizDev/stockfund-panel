# DSH 组件适配：候选热力图

本轮参考 DSH 量化终端的 `src/widgets/core/heatmap.ts`、`core/overview.ts` 和组件扩展说明，吸收布局与概览思路，使用看板既有 React 页面和数据契约实现。

## 可用位置

AI选股 → 股票 / ETF → 候选观察 → 热力图。默认仍是 Top10 卡片；两种资产分别记住展示方式、面积依据和原有筛选。点击色块进入同一候选详情，不自动触发 AI 或下单。

- 等面积模式便于横向观察；成交额模式只使用有限、正成交额，按真实相对权重布局。
- 面积过小或无正成交额的候选单独列出可点击名称，不能把缺失成交额补成虚构权重。
- 红涨绿跌；涨跌幅输入遵守看板小数制，`0.01` 为 `1%`，颜色固定在 `±5%` 饱和。
- 上涨、下跌、平盘与缺失分别统计；只反映当前显示候选，不扩展成全市场统计。
- 实时与盘后报价分别标明数量。候选排名仍使用原有策略排名，不按热图位置重新定义。

数据使用现有候选查询与缓存，不增加行情接口、轮询或个人数据读写。逻辑层保持纯函数并独立测试，渲染使用可键盘操作的按钮和当前看板的主题样式。

## 暂未接入的参考

财经日历、外汇、公司资料等仍需具体可用源和字段口径。文档中的接口参考不代表现成功能；本轮不添加无数据页面，也不接入 DSH 默认 Binance 行情。
