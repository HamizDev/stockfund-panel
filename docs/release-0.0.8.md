# stockfund-panel 0.0.8

日期：2026-10-19。本批聚焦首次查询、港股目录备用检索和 Jevos 的上下文遗漏，保持现有深色风格与分析双图布局。

## 查询与加载

- 股票 / ETF 搜索选中结果时保留已确认的资产类型，并与证券代码一起保存在链接中，减少分钟图加载前的分类查询。没有类型的旧链接仍通过精确匹配查询，不根据代码猜资产类别。
- 已有名称时不再重复查询名称；历史分析报告的并发加载共用同一请求。失败可重试，显式重置会隔离旧请求的迟到响应。
- 缺少有效本地昨收时，在线日线核验与分钟查询并行，继续使用原有有界线程池、缓存和价格基准校验。有效本地昨收不触发预取；没有可靠基准时仍不显示涨跌幅，不用首分钟或推算比例替代。
- 这些改动减少不必要的请求与串行等待，不能消除免费来源的响应时间、缺数或限流。

## 港股目录备用搜索

- 在本地、Yahoo 和腾讯名称搜索均无匹配时，使用 HKEX 官方中英文证券名单补充定位。仅纳入港币普通股、ETF 及杠杆 / 反向产品，排除认股证、牛熊证、债券及其他币种柜台。
- 中英文记录通过官方证券代码关联；目录更新时间来自文件声明。目录只在内存有界缓存，不扫描或持久化全市场行情，不新增付费数据源。
- 目录候选不证明对应证券有实时报价、分钟历史或完整行情覆盖；简繁体名称也不保证任意写法均命中。

## Jevos

- 标题风险判断与正文首句不一致时，针对后续明确回复 / 澄清事实补入前三句的有界原文复核，减少只读首句造成的上下文遗漏。普通新闻前两次判断及既有正负混合判断保持原路径。
- 更正需要模型选择及原文证据共同支持；处罚、未履约或既有合同终止不能仅因出现否认或澄清用语变为中性。旧新闻规则标签随版本失效，审计和策略记录保留。
- 本地模型仍可能误判，低置信判断保留暂定标记。少量样本与针对性回归不构成总体准确率或投资收益承诺。

## 验证与边界

定向回归、公开版和保留本地私有接入的生产构建、本机部署读回分别记录。受控延迟对照只验证并行消除了串行等待，不代表全站或真实上游提速比例。

A股本次检查时已经收盘。开盘期间连续行情年龄、ETF 分钟更新和相同股票池的涨跌停统计仍需在交易时段采样；盘后结果不代替盘中验收。

本批不迁移行情或历史账本，不更改模拟账户策略、额度、杠杆、交易所设置或真实账户。免费来源可能延迟或不可用。
