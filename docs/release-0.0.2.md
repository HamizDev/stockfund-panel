# stockfund-panel 0.0.2

## 图表与研究组件

- 行情浏览和数字资产使用本地 Canvas 图表；专项分析、净值等继续使用已有 ECharts 图表，保留现有深色界面。
- 股票/ETF 分析增加独立分钟面板，支持分时、真实 OHLC 分钟 K、日期选择和日线联动。只有价格点的数据保持折线展示，不伪造蜡烛。
- 股票/ETF 日线图下增加本地技术分项摘要：EMA20/60、Wilder RSI14、MACD(12,26,9)、前 20 根 Donchian 通道。
- 显示已加载区间首收至末收涨跌、最高/最低和按收盘价计算的最大回撤；这些是研究数据，不是策略收益或自动下单信号。
- EMA 采用前 N 根 SMA 预热；MACD 柱为 `2 × (DIF − DEA)`；通道突破排除当前 K 线。历史不足明确显示不足。
- 参考 DSH 提供的组件设计与指标说明，使用已有本地行情计算；不嵌入远端 TradingView 挂件，也不承诺文档中尚未实现的组件。

## 官方模拟与本地模拟

- 增加 OKX 官方模拟的三套独立策略归因：BTC 通道突破、ETH 均线趋势、SOL 回调。每套 10 USDT 保证金预算、逐仓 10 倍、最大入场名义金额 90 USDT。
- 三套策略共享一个官方模拟账户，以不同标的隔离归因，并非三个交易所子账户。需要显式启用、有效模拟专用凭据和只读预检通过；重启后需重新武装。
- IOC 限价、实际成交对账、部分成交与不确定订单暂停、费用统计、完成回合胜率和独立风控记录均在本地展示。没有成交时不生成胜率。
- 不自动改变官方账户模式、杠杆或已有持仓；暂停不会平掉已有仓位。资金费暂未分摊到三套策略绩效中。
- Bitget 官方模拟连接默认选择 UTA，可手动选择 Classic；凭据输入在连接后清空，错误仅展示有限的脱敏诊断类别。

## 其他已整理功能

- ETF 自动模拟、只读历史重放、净值与账户对照、名称优先展示。
- 免费数据源路由、竞价研究、快讯缓存、持仓研究和页面浏览状态保留。
- Pine 策略思路以本地规则重新实现；不把历史研究结果当作未来收益。

## 升级与公开范围

版本元数据统一为 0.0.2。保留既有配置、账本和数据结构；新增官方策略账本默认关闭，不迁移或覆盖旧成交。

公开仓库仅包含应用源码、通用测试、文档和必要静态资源。不包含个人 data、真实凭据、`.env`、登录态、本机部署脚本、运行环境或仅供自用的 AxData 接入。使用者需要自行配置合法可用的数据源与模拟专用凭据。
