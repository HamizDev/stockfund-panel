## 数据与隐私

- 价格、日期、策略命中、账户、净值及成交均为合成示例；不代表真实行情、历史回测成绩或策略表现。
- 图片保留“README 演示 · 合成数据 · 未调用 AI 或交易服务”标记。
- 截图过程没有连接真实后端、券商或交易所账户，也没有调用 AI 服务。
- 没有使用个人持仓、交易记录、访问密码、API Key 或登录态；公开证券名称仅用于界面展示。
- 图片仅展示功能布局，不构成证券推荐或收益承诺。

更新截图时应继续使用独立演示数据，检查文字和图表加载完成、没有错误提示，并人工复查每张图片后再发布。
