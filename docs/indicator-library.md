# 指标研究库

## 使用

数据工具的「指标研究」入口打开研究库；本机研究资料页也可用相同面板。保持原界面主题，不增加侧栏菜单。

- **已有研究**：四套已接入数字资产研究回测的规则说明，列出输入、入场、退出及局限。回测仍在原研究页执行，本页不会启用策略。
- **在线发现**：输入中文主题或选择快捷主题，再点查询。填写作者账号时按作者检索；主题搜索是主题目录，不保证任意关键词的全文召回。支持指标、策略、函数库和分页。
- **按需查看源码**：只在点击时读取公开 Pine 文本，显示实际版本、Pine 语言版本、大小及获取时间。受保护脚本不会读取。源码按文本展示，可复制；不自动执行或改写交易策略。
- **离线检索**：检索已经发现的脚本名称、作者、摘要、主题及已缓存源码。例如 `ta.rsi`、`strategy.entry`。没有缓存的源码不可离线打开，不会偷偷转为联网。

页面切换保留当前条件与所选源码；切换脚本释放上一份不再使用的前端查询，页面离开后的查询保留 30 分钟。表单状态仅存当前浏览器会话，不保存源码到浏览器存储。

## 缓存与请求边界

不安装或启动额外 MCP 进程。使用现有 Python/FastAPI 扩展注册和前端统一 API、查询键、TanStack Query 缓存。

- 目录是随代码提供的规则说明，不访问上游。首页、实时行情、自动交易不调用研究接口。
- 在线列表缓存 6 小时，最多 20 个搜索结果页、200 条脚本目录。每页最多展示 24 项。
- 源码最多 40 份，单份 256 KiB，总计 6 MiB；只保留最近读取的版本。此库不是全部 TradingView 脚本的镜像。
- 明确版本优先命中缓存；`last` 只在 6 小时有效期内命中，过期重新核对。离线模式显示已存的实际版本，不能把旧版本说成最新。
- SQLite 缓存位于运行 data 的 `cache/indicator-library.sqlite`；按需创建，无账户或凭据。页数上限 4096（默认 4 KiB 页约 16 MiB），删除旧记录后的空页可复用，不持续无限膨胀。
- SQLite 事务预留跨进程请求配额：至少间隔 2 秒，按 UTC 自然日最多 100 次请求。401/403/429 暂停在线请求 15 分钟。该限制是本机节流规则，不是网站授予的调用额度。
- 固定 HTTPS 域名，不使用用户 Cookie、交易 API Key、代理登录或任意 URL。禁止重定向；10 秒网络超时，响应最多 2 MiB。网络失败显示明确错误，离线目录继续可用。

不改变行情源、全量分钟采集、策略门槛、账户、杠杆、资金预算、历史成交、自动运行状态及版本号。

## 实现参考与许可

公开接口的形状、开放脚本筛选与按需源码的思路参考 [tradingview-indicator-search-mcp-server](https://github.com/daviddme/tradingview-indicator-search-mcp-server)。适配在当前后端实现，没有照搬其进程、MCP 配置或批量采集机制。相关 MIT 通知保留在 [third-party/tradingview-indicator-search-mcp-server.txt](third-party/tradingview-indicator-search-mcp-server.txt)。

工具软件的 MIT 许可不替代 Pine 作者自己的许可。缓存保留源码原文和作者信息；本项目不把在线获取的第三方 Pine 代码加入公开仓库。使用具体脚本另行遵循其作者声明。

公开接口可能变更、被限制或不可达。热度和点赞不是胜率，公开源码也不意味着没有重绘或未来数据风险。迁移规则前应核对收盘确认、多周期对齐、重绘、费用、滑点和成交时序，并通过原研究流程验证。
