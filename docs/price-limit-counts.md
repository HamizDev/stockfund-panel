# 涨跌停计数与盘口证据

首页及梯队的涨跌停家数按同一交易日的最新/收盘价与限价判定。历史分区使用日线，盘中可由实时行情覆盖；五档盘口仅附加封单证据，不扣减价格计数，不将不同时间的未封快照自动改成炸板或翘板。

`sealed_counts_up/down` 只包含该方向价格触板标的；`real` 表示有封单、`fake` 表示快照未封、`pending` 表示缺少可用盘口证据。旧字段名保持接口兼容，不代表假报价。缺少盘口记录不等于未封。

标的维表 `as_of` 是维度同步日期，不是限价的行情日期。数据源可以返回 `ext.limit_price_date`（`YYYY-MM-DD`）；StockSDK 从腾讯报价的时间戳按上海时区提取。该字段与目标行情日匹配时才使用维表限价。新格式字段为空或过期时使用项目的涨跌幅规则及真实昨收；旧格式没有该字段时兼容 `as_of`。新股无涨跌幅限制窗口继续生效。
