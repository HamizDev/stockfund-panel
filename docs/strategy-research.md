# 股票 / ETF：从 AI 辅助到虚拟仓

## 1. 理解或生成规则

打开「策略」，先选择股票或 ETF。可以用「创建策略 · AI」描述想法，生成草案后检查规则、数据要求和买卖条件，再保存策略。选择已有策略后，「AI 解释所选策略」调用设置中已配置的 AI 助手，解释该规则；不会自动保存配置或下单。模型输出需要核对，不能当作已验证收益。

## 2. 用历史验证

「带入历史回测」只带入策略和市场，不自动运行任务。选择区间、资金、成本和成交规则，再运行回测。仓位模拟受资金及持仓限制；全量候选统计不能直接视为账户收益。

「AI 解读上次成功回测」发送实际成功结果的策略、日期、费用和统计摘要，不使用当前表单冒充旧结果。结果中的收益/回撤/胜率是小数比例；虚拟仓表中的百分比是百分数值。观察费后收益、回撤、已平仓样本数及样本外验证，单看胜率无法判断策略优劣。

## 3. 创建独立虚拟仓

「准备独立虚拟仓」带入创建表，仍需手动核对。每个策略在股票、ETF 市场分别有独立账户；首次创建买卖跟单规则默认暂停。重复创建返回同一市场已有账户，保留资金和启用状态。虚拟仓使用当前已保存的策略，不自动复制回测中的临时参数、区间、过滤、仓位或费用；想让参数一致，应先明确保存策略配置并核对账户规则。

策略仓监控只观察自己的市场；创建后监控开启、订单跟单暂停。点击「启用」后，新信号通过现有模拟引擎生成 `next_open` 订单，后续交易日日线开盘结算。暂停仅禁止新信号订单，已存在的待成交订单仍可能成交；冻结账户会拒绝新订单。电脑、后端、行情、策略监控和盘后结算必须正常工作，关闭电脑后不会继续运行。没有信号、休市、缺数据或资金不足都可能没有成交，页面启用不等于已经成交。

表格支持股票/ETF 筛选和收益、胜率、回撤排序。胜率按扣费后的 FIFO 已平仓回合统计，显示胜单/回合；确认零回合时显示 `— (0/0)`，未知样本不当作零，未平仓不计入。收益与权益只读取行情完整的已保存盘后净值，不用成本估值填补；无净值显示「待盘后定版」，缺行情或旧记录无法确认估值质量时显示待核对。回撤要求整个已保存净值序列的估值质量明确且完整。当前持仓数量和历史净值日期并非同一时点。分红和 ETF 交易规则仍有简化；模拟收益不等于实盘可实现收益。

## 图表

普通股票/ETF 详情共用 TradingView Lightweight Charts 日K视图，可看蜡烛、成交量、MA5/10/20/60、十字线与精确日期的交易标记。刷新相同标的保留缩放，切换标的或日期区间重置。数据仍来自已配置的数据源和本地缓存，图表库不提供行情。

「专业指标」保留 ECharts、扩展指标和区间标注。需要回测区间或带日期范围价格线时自动选择专业图；个股分析的支撑压力和通道布局保持专业图。股票日K沿用后端复权口径，不把原始成交价新增到前复权图中混用。

本流程只做本地模拟，不连接券商账户或真实下单接口。个人数据、API Key 和 Codex 登录信息均不属于公开源码。

研究按钮仅在点击时调用 AI，使用设置中已配置的模型并消耗相应额度。每次研究新建独立对话，只发送所示研究摘要，不附带既有聊天历史；后续可在助手里继续追问。输入过长会提示缩小范围，不会静默截断结果。
