# stockfund-panel 0.0.5

发布日期：2026-10-18。

本版本增加三市场首页、港美股公开市场快照与固定样本分析。

## 三市场首页与公开快照

- 首页可在 A股、港股和美股之间切换，保留现有页面样式。
- 港美股使用无需付费 Key 的东方财富公开行情批量分页快照，进程内缓存 5 分钟；后台完成一轮采集后原子发布，刷新期间保留上一份完整快照。
- 港股范围使用 m:128+t:3，对应港股主板股票；美股范围使用 m:105、m:106、m:107，覆盖多个上市市场，其中可能包含基金、信托和权证，不代表全部普通股。
- 展示行情源报价时间 quote_at 与本机采集时间 fetched_at。字段映射包括 f2 价格、f3 涨跌幅、f5 成交量、f6 成交额、f8 换手率、f12 代码、f13 市场、f14 名称、f100 行业和 f124 源报价时间（按当前样本映射）。
- 页面计算市场涨跌分布、均值与中位数、涨跌幅 ±3% 强弱分组、行业等权热度，以及涨跌成交额和换手率排行。
- A股行业面板读取温热缓存；缓存冷时等待后台快照，不触发全历史同步。

## 固定样本研究

- 固定观察池的 Yahoo Finance 约 3 个月日线计算 MA5、MA20、MA60、近 5 与 20 个交易日涨跌、60 个交易日区间高低和成交量。
- 产业热度使用 25 个主题的固定代表公司等权篮子，包含 CPO、PCB、半导体、存储、AI、黄金矿业等主题；默认香港时间 08:00 至 20:00 使用 A股篮子，其余时间使用美股篮子。可手动切换，并查看成分与覆盖数。

## 数据范围与限制

港股一次完整分页验收取回 2,620 条，其中 2,395 条具有同日有效报价，耗时约 5 秒。该结果记录一次验收观测，不代表每条行情都有效或持续性能保证。本机美股全量分页遇到连接中断时，明确降级为 Yahoo 活跃/涨幅/跌幅预设筛选池；页面标明选择偏差，不将其统计称为全市场广度。美股产业篮子另用腾讯已知代码批量报价，显示源站日期，时区和延迟未声明。

免费公开源可能延迟约 15 分钟或更久，也可能限流、变更；不保证实时行情或 SLA。固定观察池不是全市场样本，日线不代表复权总回报；末根 K 线可能尚未结束，成交量未按盘中时间校正。产业篮子不是官方产业指数，也不是商品现货、期货或实时暗盘数据。

字段接口参考：[AKShare 官方仓库 stock_feature/stock_hist_em.py](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_hist_em.py)。功能范围和上游约束见[港美股数据范围与口径](global-markets.md)。
