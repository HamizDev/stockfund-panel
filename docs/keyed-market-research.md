# 美股补充数据与舆情

设置 → 数据源 → **美股补充数据与舆情**，分别填写自己申请的 Finnhub / Adanos API Key，点击“验证并保存”。这会向对应官方 API 发起一次只读验证；Adanos 验证会消耗一次请求。不要填写 Finnhub Webhook Secret。

Key 沿用本机 `data/user_data/secrets.json` 凭据存储，属于普通 JSON，不是加密文件。该目录被 Git 忽略，浏览器只保留输入框的短暂状态，保存成功或失败后都会清空。服务只返回脱敏状态，不把 Key 放进 URL、行情响应或查询缓存。服务器已有认证中间件仍适用；未修改访问权限或账户配置。同名环境变量为后备，移除本机值后环境变量仍可能生效。

## 读取范围

- **Finnhub**：打开美股研究或切换当前美股股票/ETF时，按需读取补充报价、公司资料和近7个UTC日期的新闻，不轮询。报价共享缓存60秒、公司资料24小时、新闻30分钟；权限不足和缺资料分别提示，不影响原日K/分钟K。报价时间仅使用源端时间戳，缺失留空；涨跌幅为小数制，市值统一美元（源字段为百万美元）。股类代码使用明确映射，如 `BRK-B` → `BRK.B`。未使用付费K线端点，未改变原行情源或全市场采集。
- **Adanos**：美股研究的舆情摘要中选择一个来源，再点击“手动查询”。每次只请求 Reddit、新闻、X、Polymarket 之一，默认新闻；不在页面打开、聚焦或定时任务中自动查询。结果最多缓存一小时，共用有界LRU，切换标的及缓存淘汰可能提前释放；缺数据不补成中性。Free 官方当前为每月250次、30天历史、非商用，服务端限流时停止重试。配额由官方全部客户端共享，本机不承诺远端剩余额度。

美股补充研究是独立数据区，不能替代主图报价时间或覆盖标注。不将结果自动用于模拟盘、监控下单或真实交易。港股、A股、指数以及加密币不通过此补充接口；未配置Key时不向上游发请求。

## 复用边界

现有全局研究扩展路由注册与共享缓存负责接线；统一 `api.ts` / `queryKeys.ts` 负责前端访问。现有设置页和美股研究页没有对应插槽，因此只做最小源码挂载。凭据保存/移除共用存储层互斥锁，避免同进程中其他设置并发写入丢字段；不迁移或改写原凭据。
